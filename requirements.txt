# ==============================================================================
# Autonomous Object-Sorting Robotic Arm - Dependencies Specification
# Targets:
#   1. NVIDIA Jetson Orin Nano (8GB) running Linux (JetPack 5.x / 6.x, Ubuntu)
#   2. Windows / Linux PC (Development, Testing & Simulation)
# ==============================================================================

# ------------------------------------------------------------------------------
# 1. CORE CROSS-PLATFORM DEPENDENCIES (Install on both Windows & Linux)
# ------------------------------------------------------------------------------
numpy>=1.22.0,<2.0.0
Pillow>=9.0.0
Flask>=2.2.0
requests>=2.28.0
ultralytics>=8.0.0

# ------------------------------------------------------------------------------
# 2. OPENCV COMPUTER VISION
# ------------------------------------------------------------------------------
# [WINDOWS / DESKTOP PC]:
# Install the standard PyPI precompiled wheel:
opencv-python>=4.8.0

# [JETSON ORIN NANO LINUX DEPLOYMENT NOTE]:
# DO NOT run 'pip install opencv-python' on your Jetson Orin Nano!
# JetPack provides an optimized, hardware-accelerated OpenCV build pre-installed
# with CUDA and GStreamer (nvarguscamerasrc) support. A standard pip wheel will
# overwrite JetPack's build with a generic CPU wheel that lacks GStreamer.
# If OpenCV is missing on Jetson, install the system package:
#   sudo apt-get install -y python3-opencv

# ------------------------------------------------------------------------------
# 3. JETSON / LINUX HARDWARE-ONLY DEPENDENCIES (PCA9685 I2C Servo Controller)
# ------------------------------------------------------------------------------
# These packages interface with the physical 40-pin GPIO header and I2C bus.
# On Windows, these are NOT needed: the codebase automatically detects their
# absence and switches to high-fidelity software simulation mode.
#
# On Jetson Orin Nano, install via pip:
Adafruit-Blinka>=8.0.0
adafruit-circuitpython-pca9685>=3.4.0
adafruit-circuitpython-motor>=3.4.0

# ------------------------------------------------------------------------------
# 4. PYTORCH / GPU ACCELERATION (Jetson Deployment Note)
# ------------------------------------------------------------------------------
# [WINDOWS]:
#   pip install torch torchvision
#
# [JETSON ORIN NANO (JetPack 5.x / 6.x, ARM64)]:
# PyTorch for Jetson cannot be installed from standard PyPI. Download and install
# the official NVIDIA wheel matching your JetPack version, for example:
#   sudo apt-get install -y libopenblas-base libopenmpi-dev
#   pip install --no-cache https://developer.download.nvidia.com/compute/redist/jp/v512/pytorch/torch-2.1.0a0+41361538.nv23.06-cp38-cp38-linux_aarch64.whl
